Now we need to define the minimal architecture.

Andrej Karpathy's [llm-wiki.md](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) is a good starting point. 

The problem Andrej Karpathy's llm-wiki tries to solve is inefficient knowledge retrieval that starts over every new session. llm-wiki is a persistent, compounding artifact. 

There are three layers

- Raw sources: These are raw sources that gets ingested to the wiki. Raw sources are immutable.
- Wiki: LLM generated markdown files. LLM maintains this layer and humans rarely touch it.
- Schema: [AGENTS.md](http://AGENTS.md) file that describes the wiki structure and how it's maintained.
